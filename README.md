# 基于多Agent协作的虚假新闻识别与溯源系统
**毕业设计项目 | AI多Agent应用 | 自然语言处理 | 虚假新闻检测**

## 📌 项目简介
本项目构建了一套**多Agent协同**的虚假新闻全链路识别系统，解决传统单模型检测仅能识别文本、无法多模态解析、人工审核效率低、误检率高的行业痛点。

系统包含4大协同工作Agent：
1. **多模态解析Agent**：文本实体提取、图片/视频内容分析
2. **可信度评估Agent**：LSTM模型+大模型长链推理、信源交叉验证
3. **溯源分析Agent**：生成传播链路图谱、新闻溯源定位
4. **人工交互Agent**：可解释报告、闭环优化反馈

## 🎯 核心量化成果（匹配毕业设计数据）
- ✅ 数据集规模：10w+条新闻数据
- ✅ 单条数据Token消耗：≈3000
- ✅ 误检率：从 **22% 降至 7%**
- ✅ 审核效率提升：**75%**
- ✅ 日处理能力：2000条新闻

## 🛠️ 技术栈
- 模型：LSTM、大模型长链推理
- 架构：多Agent协同系统
- 可视化：NetworkX传播图谱
- 语言：Python

## 🚀 快速运行
1. 安装依赖：`pip install -r requirements.txt`
2. 运行主程序：`python main.py`
3. 查看输出：自动生成检测报告+新闻传播溯源图谱
